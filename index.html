Applicatie en databeheer Gedaan

Applicatie en databeheer is de richting dat ik in het middelbaar heb gedaan. Dit was een traject van 2 jaar. Tijdens dit traject heb ik het eerst jaar alles gezien van HTML, CSS en Javascript. Het tweede jaar heb ik bootstrap en PHP gezien dit bouwde steeds verder op elkaar. Ook heb ik 1 jaar netwerken gezien en 1 jaar hardware. Ook heb ik her eerst semester flowgorithem gehad dit heeft mij de mindset van programmeren geleerd. Hier hebben we dan de komende 3 semesters op verder gebouwd met C#.

  • HTML / PHP / JS / CSS
  • Flowgoritm / C#
  • Netwerken
  • Hardware

Systeem en netwerkbeheer bezig

Systeem- en netwerkbeheer is het traject dat ik nu volg. Hierin leer ik de volledige IT-infrastructuur van een organisatie ontwerpen, bouwen, onderhouden en beveiligen. Ik start met hardware en besturingssystemen (Windows Server en Linux), en bouw daarop verder met serverinstallatie, Active Directory en scripting via PowerShell en Bash. Daarnaast ga ik ook leren over computernetwerken, zoals IP-planning, switches en routers configureren, VLAN's en VPN's. Hopelijk rond ik dit traject goed af.

  • Python
  • Windows Server
  • Linux
  • Tailwind
  • Cisco

Stage PC-yellow gedaan
